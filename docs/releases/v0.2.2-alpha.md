# SilkMC v0.2.2-alpha

SilkMC v0.2.2-alpha builds on the Minecraft **26.2** baseline from `v0.2.1-alpha` and
adds live server-health boss bars for quick, in-game performance observability.

## New: server-health boss bars

A pair of opt-in boss bars can now be toggled per player, giving operators an at-a-glance
read on how well the server (and the player's own region) is holding up — handy for
testing, benchmarking, and load checks without leaving the game.

- **TPS bar** — shows `TPS`, `MSPT`, and the player's `Ping`. The TPS and MSPT values are
  read from the tick data of the region the player is standing in (Folia region threading),
  falling back to the global region schedule when the player is not inside a ticking region.
- **RAM bar** — shows used/max heap in MB and the corresponding percentage, sourced from the
  JVM at runtime.
- Both bars are colored green/yellow/red so the current state is readable at a glance, and
  they refresh once per second on a shared daemon thread. The refresh is off the region
  threads, so enabling the bars does not add work to server ticks.

### Usage

```
/silkmc bars
```

Run the command to toggle the bars on; run it again to hide them. The subcommand requires
the existing `silkmc.command` permission (default: OP) and is tab-completable alongside the
other `/silkmc` subcommands (`status`, `plugins`, `report`, `reload`, `bars`). Only players
can toggle the bars.

## Notes

- The Minecraft `26.2` baseline (`mcVersion`/`apiVersion` `26.2`, Paper base
  `2717585e686d7d294cabce9f1753280780ecf847`) and all 26.2 region-threading patches from
  `v0.2.0-alpha` / `v0.2.1-alpha` are preserved and unchanged.
- The feature is implemented entirely within the maintained SilkMC server module
  (`gg.tame.silkmc.server.bars.ServerStatusBars`) and wired in through the existing
  `/silkmc` command, so it adds no changes to upstream Paper/Folia command registration.

## Build

```powershell
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-25.0.2.10-hotspot'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
./gradlew applyAllPatches
./gradlew build
./gradlew :silkmc-server:createPaperclipJar
```

Run with:

```powershell
java -Xms4G -Xmx4G -jar .\silkmc-server\build\libs\silkmc-paperclip-26.2.local-SNAPSHOT.jar nogui
```
