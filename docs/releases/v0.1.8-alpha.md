# SilkMC v0.1.8-alpha

SilkMC v0.1.8-alpha advances the declared platform target to Minecraft `26.2` and corrects a repository consistency defect in the plugin-compatibility subsystem.

## Highlights

- Target Minecraft version bumped to `26.2` (`mcVersion` and `apiVersion`). The `README` "Current state" now reflects the `26.2` baseline and the `v0.1.8-alpha` project stage.
- Resync the tracked `SilkPluginCompatibility` reference snapshot with its authoritative patch. The committed snapshot had drifted behind the patch set and was missing public API that other SilkMC components depend on — most notably `reloadConfiguration()` (invoked by `/silkmc reload` in `SilkMCCommand`), along with the plugin-override support (`overrideFor`, `markWarned`, `requiresExplicitDeclaration`, `shouldWarnOnLoad`), the `silkmc-plugin-overrides.yml` loading path, and consistent plugin-name normalization in the warning-dedup set. Reviewers reading the tracked source now see the same behavior the build produces.

## Compatibility

- Plugin classification, enforcement, and override handling are unchanged from `v0.1.7-alpha`; this release only aligns the reviewable snapshot with the shipped behavior and updates version metadata.
- Region-threading, scheduler bridging, and locator-bar behavior are unaffected.

## Notes

- The upstream baseline sync to a Folia `26.2` commit (`paperRef`) is tracked separately; the declared MC/API version has been advanced to `26.2` as the release target.
