# SilkMC v0.1.8-alpha

SilkMC v0.1.8-alpha is a maintenance release on the Minecraft `26.1.2` baseline.

## Notes

- An earlier revision of these notes claimed a fix for `/help`, `/pl`, etc. rendering
  red/unknown. That claim has been retracted: the change (switching
  `Commands.sendCommands` from `taskScheduler.schedule(..., null, 1L)` to
  `taskScheduler.scheduleOrExecute(...)`) is a no-op for this code path — the command
  tree is built on an async pool thread, where `scheduleOrExecute` simply falls back to
  the same `schedule(..., null, 1L)` behavior. The red/unknown command symptom is not a
  SilkMC backend issue.
- Region-threading, locator-bar, and plugin-compatibility behavior from prior releases
  are unchanged.
