# SilkMC v0.2.1-alpha

SilkMC v0.2.1-alpha is a rebuild on the Minecraft **26.2** baseline. It carries forward
the full 26.2 rebase from `v0.2.0-alpha`.

## Notes

- An earlier revision of these notes claimed a fix for `/help`, `/pl`, etc. rendering
  red/unknown. That claim has been retracted: the change (switching
  `Commands.sendCommands` from `taskScheduler.schedule(..., null, 1L)` to
  `taskScheduler.scheduleOrExecute(...)`) is a no-op for this code path — the command
  tree is built on an async pool thread, where `scheduleOrExecute` simply falls back to
  the same `schedule(..., null, 1L)` behavior. The red/unknown command symptom is not a
  SilkMC backend issue.
- The Minecraft `26.2` baseline (`mcVersion`/`apiVersion` `26.2`, Paper base
  `2717585e686d7d294cabce9f1753280780ecf847`) and all 26.2 region-threading patches and
  API-break fixes from `v0.2.0-alpha` are preserved and unchanged.

## Build

```powershell
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-25.0.2.10-hotspot'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
./gradlew applyAllPatches
./gradlew build
./gradlew :silkmc-server:createPaperclipJar
```

Run with:

```powershell
java -Xms4G -Xmx4G -jar .\silkmc-server\build\libs\silkmc-paperclip-26.2.local-SNAPSHOT.jar nogui
```
