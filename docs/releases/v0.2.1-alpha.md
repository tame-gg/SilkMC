# SilkMC v0.2.1-alpha

SilkMC v0.2.1-alpha is a bugfix release on the Minecraft **26.2** baseline. It carries
forward the full 26.2 rebase from `v0.2.0-alpha` and adds the client command-tree
synchronization fix that previously shipped for the 26.1.2 line, so `/help`, `/pl`, and
other commands no longer render red/unknown.

## Highlights

- Fix `/help`, `/pl`, and other commands appearing red/unknown in the client even though
  they still executed server-side. `Commands.sendCommands` synchronized the client's
  command tree via a 1-tick delayed entity task (`taskScheduler.schedule(..., null, 1L)`).
  Under Folia region threading that delay could run *after* the client had already
  processed the join/command packets, leaving the client's command tree unsynchronized.
  The sync now uses the guaranteed immediate/queued `taskScheduler.scheduleOrExecute(...)`
  path, which runs inline when already on the owning region thread or enqueues onto it
  otherwise, with no artificial delay.
- Built and verified against the Minecraft `26.2` baseline (`ver/26.2.x`), Paper base
  `2717585e686d7d294cabce9f1753280780ecf847`.

## Minecraft 26.2 baseline

- `mcVersion` and `apiVersion` are `26.2`, unchanged from `v0.2.0-alpha`.
- All 26.2 region-threading patches, the locator-bar / region-threading waypoint support,
  and the 26.2 API-break fixes (`TickData` repackaging, `Entity#getRandom()`,
  respawn-anchor charge routing, teleport bridge) from `v0.2.0-alpha` are preserved.

## Notes

- No command behavior changed server-side; only the timing of client command-tree
  synchronization was affected. Commands that previously rendered red already executed
  correctly — they now render as valid.
- The new pattern matches how the rest of the region-threading base patch schedules
  per-entity work.

## Build

```powershell
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-25.0.2.10-hotspot'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
./gradlew applyAllPatches
./gradlew build
./gradlew :silkmc-server:createPaperclipJar
```

Run with:

```powershell
java -Xms4G -Xmx4G -jar .\silkmc-server\build\libs\silkmc-paperclip-26.2.local-SNAPSHOT.jar nogui
```
